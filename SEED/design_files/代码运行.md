# SEED ALFWorld 训练运行指南

## 一、环境准备

创建虚拟环境并安装依赖：

```bash
# 创建 conda 环境（推荐）
conda create -n seed python=3.12 -y
conda activate seed

# 安装依赖
cd self-learning/SEED
pip install -e .
```

下载 ALFWorld 数据（约 4GB）：

```bash
alfworld-download -f
```

数据将下载到 `~/.alfworld/` 目录。

---


## 二、模型下载

### 方案 A：使用 OPID-ALFWorld-1.7B（推荐）

下载作者提供的、**已在 ALFWorld 数据上预训练**的模型，此模型是作者另一项工作预训练的，具备 ALFWorld 任务能力，baseline rollout 成功率更高一些，构造数据效率更高。：

```bash
cd self-learning/models

huggingface-cli download Jinyang23/OPID-ALFWorld-1.7B \
    --local-dir OPID-ALFWorld-1.7B \
    --local-dir-use-symlinks False
```
### 方案 B：使用原始 Qwen3-1.7B

如想从头开始训练模型，也可以使用基础模型：

```bash
cd self-learning/models

huggingface-cli download Qwen/Qwen3-1.7B \
    --local-dir Qwen3-1.7B \
    --local-dir-use-symlinks False
```

## 三、SFT 训练

### 3.1 数据准备

```bash
cd self-learning/SEED

# 设置策略模型路径
export MODEL_PATH=self-learning/models/OPID-ALFWorld-1.7B
export OUTPUT_DIR=self-learning/SEED/outputs/alfworld_data

# 设置 ALFWorld 数据路径
export ALFWORLD_DATA=self-learning/alfworld_data

# 设置 OpenAI API 用于Skill生成
export OPENAI_BASE_URL=your-base-url
export OPENAI_API_KEY=your-api-key
export OPENAI_MODEL=your-model


bash scripts/sft/alfworld/prepare_data.sh
```

### 3.2 SFT 训练

```bash
cd self-learning/SEED

export MODELS_ROOT=self-learning/models

export DATA_DIR=self-learning/SEED/outputs/alfworld_data
export EXPORT_MODEL_DIR=self-learning/models/Qwen3-1.7B-alfworld-sft

bash scripts/sft/alfworld/train_sft.sh
```

## 四、RL 训练

```bash
cd self-learning/SEED

export HF_MODEL_PATH=self-learning/models/Qwen3-1.7B-alfworld-sft
export MODEL_PATH=self-learning/models/Qwen3-1.7B-alfworld-sft
export DEFAULT_LOCAL_DIR=self-learning/SEED/outputs/rl/alfworld_qwen_self

# 可选，如果安装flash-attn出问题，就使用 SDPA 注意力后端（避免安装 flash-attn）
export VLLM_ATTENTION_BACKEND=TORCH_SDPA

bash examples/seed_trainer/run_alfworld_sft_qwen_self.sh
```

## 五、模型合并

```bash
cd self-learning/SEED

python3 scripts/model_merger.py merge \
    --backend fsdp \
    --local_dir outputs/rl/alfworld_qwen_self/global_step_160/actor \
    --target_dir models/alfworld_qwen_rl_final
```
